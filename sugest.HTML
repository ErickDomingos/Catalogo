Sugerir um jogo

Experimente sugerir um título. Este formulário é uma demonstração: os dados são validados aqui, sem envio, armazenamento ou resposta por e-mail.

Quer só guardar um jogo para você, sem revisão de ninguém? Use Adicionar um jogo ao meu acervo, na página do catálogo — o site tenta salvá-lo no seu navegador e avisa caso o armazenamento esteja bloqueado.

Formulário de sugestão

Campo obrigatório.

Use um endereço de exemplo, como teste@example.com. Nenhum e-mail será enviado.

Em quais plataformas você jogou?

Dois ou três argumentos bastam. Campo obrigatório.

Como testar a sugestão

  • Informe um título e um e-mail de exemplo.
  • Escolha o gênero e, se quiser, as plataformas.
  • Escreva uma justificativa curta.
  • Acione “Simular envio” e confira a confirmação.

Como este é um projeto acadêmico, o formulário não envia dados para nenhum servidor: o retorno é gerado no próprio navegador.
